# demkabob
демкабоб квадратные штаны подогнал тебе базовый лист команд нужных для сдачи первого модуля ДЭМО экзамена йоу. 

Этот репо будет обновлятся в тандем с моей подготовкой к экзамену. Важно понимать что тупое переписывание этих команд магически не решит вашу неподготовленность. Вам НУЖНО знать что происходит и что вы пишите иначе вам заказан люкс номер в Troubleshooting Hell.
